1. Project Overview

Aladdin is a production-grade, multi-agent AI investment research system inspired by Benjamin Graham's "The Intelligent Investor". Given any company name or ticker, it:

  1. Resolves the ticker and fetches live financial data (scraping Google Finance, Yahoo, Screener.in, StockAnalysis.com)
  2. Runs 4 parallel analyst agents (Fundamentals, Sentiment, Geopolitics, Valuation)
  3. Synthesizes everything into a hedge-fund-quality investment report
  4. Delivers a clear INVEST / PASS decision with Margin of Safety

Key Differentiators

  • Supports both public companies (US + Indian markets) and private/unlisted companies
  • Zero-API-key mode: Works with comprehensive mock data when keys are missing
  • Real-time data scraping: No paid API dependency for financial data
  • Session-aware chat: Follow-up Q&A about any generated report
  • PDF export: Browser print API for clean styled reports

Data Fetch Chain (Step 1 Detail)

  1. searchTicker(query) → Yahoo Finance Search API + local fallback map
  2. If not found → private company path: web search + LLM validates existence
  3. fetchCompanyProfile(ticker) → Google Finance scraping + Yahoo Quote + quoteSummary
  4. fetchFinancialMetrics(ticker) → Google Finance + Screener.in (India) / StockAnalysis.com (US)
  5. fetchHistoricalFinancials(ticker) → Screener.in P&L / StockAnalysis financials
  6. fetchCompanyNews(ticker) → Google News RSS feed

7. Agent Pipeline (Backend Core)

7.1 State Definition — src/lib/agents/state.ts

Central contract. Every node reads from and writes to AgentState:

interface AgentState {
  query: string;
  company: CompanyProfile | null;
  rawFinancials: Record<string, unknown> | null;  // { metrics, historicalData }
  newsItems: NewsItem[];
  fundamentals: FundamentalAnalysis | null;
  sentiment: SentimentAnalysis | null;
  geopolitics: GeopoliticsAnalysis | null;
  valuation: ValuationAnalysis | null;
  decision: InvestmentDecision | null;
  scrapedUrls?: { title: string; url: string; confidence: number }[];
  errors: string[];
  status: 'idle' | 'fetching' | 'analyzing' | 'deciding' | 'complete' | 'error';
}

Key Sub-Interfaces

  • FinancialMetrics: P/E, P/B, EPS, ROE, D/E, current ratio, FCF, margins, growth, dividend yield, market cap, book value
  • CompanyProfile: name, ticker, exchange, industry, sector, country, currency, price, 52-week range, logo, weburl
  • FundamentalAnalysis: metrics, grahamChecklist[], highlights[], historicalData[], score (0-100), analysis (markdown)
  • SentimentAnalysis: overallSentiment (enum), sentimentScore (0-100), newsItems[], socialMentions[], analysis
  • GeopoliticsAnalysis: risks[] (factor, severity, likelihood, desc), opportunities[], macroIndicators[], analysis
  • ValuationAnalysis: grahamValue, dcfValue, intrinsicValue, currentPrice, marginOfSafety, scenarios, analysis
  • InvestmentDecision: action (INVEST|PASS|WAIT_MONITOR), confidenceScore, targetPrice, stopLoss, timeHorizon, reasoning, sources[], disclaimer

7.2 LLM Factory — src/lib/agents/llm.ts

  • createLLM(opts?): Returns ChatOpenAI | null
  • Auto-detects provider: gsk_* → Groq | sk-* → OpenAI
  • Defaults: temperature 0.3, maxTokens 1200

7.3 Graph Orchestrator — src/lib/agents/graph.ts

  • runInvestmentAnalysis(query, onProgress?): Main entry point
  • Step 1: dataFetcherNode (sequential)
  • Step 2: Promise.all([fund, sent, geo, val]) wrapped in safeRun()
  • Step 3: decisionNode (sequential)
  • safeRun(name, fn): Prevents one analyst failure from crashing pipeline

7.4 Node: Data Fetcher — src/lib/agents/nodes/fetcher.ts

Reads: state.query | Writes: company, rawFinancials, newsItems, scrapedUrls, errors, status

  • Resolves ticker via searchTicker() → Yahoo Finance Search
  • Private company path: web search + LLM validates existence, extracts profile
  • Public company: scrapes Google Finance + Screener.in/StockAnalysis + Yahoo
  • Fetches news via Google News RSS
  • Stores rawFinancials as { metrics, historicalData }

7.5 Node: Fundamental Analyst — fundamentals.ts

Reads: company, rawFinancials | Writes: fundamentals

Builds Graham's 10-Point Defensive Investor Checklist:

  1. Adequate Size (Market Cap > $2B)
  2. Strong Financial Condition (Current Ratio > 2.0)
  3. Earnings Stability (Positive EPS)
  4. Dividend Record (Yield > 0%)
  5. Earnings Growth (Revenue Growth > 0%)
  6. Moderate P/E (< 20)
  7. Moderate P/B (< 2.5)
  8. Conservative Debt (D/E < 1.0)
  9. Positive Free Cash Flow
  10. Healthy Profit Margin (> 5%)

Private companies use a 5-point VC/PE checklist instead.

7.6 Node: Sentiment Analyst — sentiment.ts

Reads: company, newsItems | Writes: sentiment, scrapedUrls

  • Searches web for market sentiment data
  • Weighted formula: news (40%) + social (30%) + search (30%)
  • Classifies: extreme_fear / fear / neutral / greed / extreme_greed
⚠️ Social media mentions (Reddit, Twitter, StockTwits) are mock/randomized data.

7.7 Node: Geopolitics — geopolitics.ts

Reads: company, newsItems | Writes: geopolitics, scrapedUrls

  • 3 parallel search queries: company risks, sector policies, global macro
  • Macro indicators hardcoded by country (US vs India)
  • LLM outputs structured JSON: { risks[], opportunities[], analysis }

7.8 Node: Valuation Expert — valuation.ts

Reads: company, rawFinancials | Writes: valuation

Graham's Revised Formula

V = EPS × (8.5 + 2g) × 4.4 / Y
  EPS = trailing twelve months
  g   = growth rate (capped 15%)
  Y   = AAA bond yield (default 4.4)

Simplified DCF

10-year projection: Years 1-5 high growth, Years 6-10 fading
Terminal value: Gordon Growth Model (2.5% perpetual)
Discount rate: 10% (hardcoded WACC)
Per-share: simplified scaling (fcf × growthMultiple × 15)

Margin of Safety

MoS = (Intrinsic Value - Current Price) / Intrinsic Value × 100%
Intrinsic Value = 50/50 blend of Graham + DCF
Graham recommends ≥ 30%

7.9 Node: Decision Maker — decision.ts

Reads: ALL outputs | Writes: decision, status

Composite Score

Fundamentals: 35%
Valuation (MoS): 30%
Sentiment: 20%
Geopolitics (inverse risk): 15%

Fallback: INVEST if composite ≥ 45 AND MoS ≥ -5%, else PASS

LLM generates full investment report. Action extracted via regex. Sources deduplicated, sorted by confidence, top 8 kept.

13. Known Issues & Technical Debt

🔴 Critical

  1. API keys in .env.example — Real keys committed; must rotate
  2. Social sentiment is fake — Random Math.random() data shown as real
  3. Macro indicators hardcoded — Not fetched live
  4. DCF model simplified — Uses scaling formula, not proper shares-outstanding DCF
  5. Chat sessions in-memory — Lost on server restart

🟡 Medium

  1. Web scraping fragile — CSS classes can change anytime
  2. No streaming — Loading steps are cosmetic 3s timers
  3. Markdown renderer regex-based — Doesn't handle all edge cases
  4. No React error boundaries
  5. Zero tests — No unit, integration, or E2E tests
  6. LangGraph dependency unused — Installed but graph compilation not used

🟢 Low

  1. Clearbit logos may not resolve for all companies
  2. No result caching — every analysis runs full pipeline
  3. Google News RSS may rate-limit

14. How to Run

git clone <repo-url>
cd alladin

# Install (--legacy-peer-deps required for React 19 peer conflicts)
npm install --legacy-peer-deps

# Setup environment
cp .env.example .env.local
# Edit .env.local — at minimum set OPENAI_API_KEY

# Development
npm run dev    # → http://localhost:3000

# Production
npm run build
npm start

# Deploy
vercel deploy  # Set env vars in Vercel dashboard

Minimum: Node.js ≥ 18, npm ≥ 9. Works without any API keys using fallback data.
